# Posts API Documentation

## 1. Project Overview

The Posts API is a Django REST Framework based backend that provides APIs for managing posts and users.

The API supports:
- Creating posts
- Listing posts
- Retrieving individual posts
- Updating posts
- Deleting posts
- File uploads with posts
- User listing with role information
- Token-based authentication
- Swagger/OpenAPI documentation

## 2. Technologies / Frameworks

- Python
- Django
- Django REST Framework (DRF)
- SQLite (local development)
- Token Authentication
- Swagger / OpenAPI
- drf-spectacular
- WhiteNoise

## 3. APIs Developed

### Posts APIs

| Endpoint | Method | Purpose |
|---|---|---|
| `/api/posts/` | GET | List all posts |
| `/api/posts/` | POST | Create a new post |
| `/api/posts/{id}/` | GET | Retrieve a specific post |
| `/api/posts/{id}/` | PUT | Update a post |
| `/api/posts/{id}/` | PATCH | Partially update a post |
| `/api/posts/{id}/` | DELETE | Delete a post |

### Users API

| Endpoint | Method | Purpose |
|---|---|---|
| `/api/users/` | GET | List users with their roles |

## 5. Create Post

### Endpoint

`POST /api/posts/`

### Purpose

Creates a new post for the authenticated user.

### Authentication

Token authentication is required.

### Content-Type

`multipart/form-data`

### Request Payload

| Field | Type | Required | Description |
|---|---|---|---|
| `title` | string | Yes | Title of the post |
| `body` | string | Yes | Content of the post |
| `file` | file | No | Optional file attachment |

### Example

'''text
title: My First Post
body: This is my post content.
file: example.pdf

Successful Response

Status Code: 201 Created

Example:

{

## 8. Update Post

### Endpoint

`PUT /api/posts/{id}/`

### Purpose

Updates an existing post.

### Authentication

Token authentication is required.

### Permission

- **Admin:** Can update any post.
- **User:** Can update only their own post.

### Content-Type

`multipart/form-data`

### Path Parameter

| Parameter | Type | Required | Description |
|---|---|---|---|
| `id` | integer | Yes | ID of the post to update |

### Request Payload

| Field | Type | Required | Description |
|---|---|---|---|
| `title` | string | Yes | Updated post title |
| `body` | string | Yes | Updated post content |
| `file` | file | No | Optional file attachment |

### Example Request

```text
PUT /api/posts/1/

Example data:

title: Updated Post
body: Updated post content.
file: updated-file.pdf
Successful Response

Status Code: 200 OK

Example:

{
    "id": 1,
    "user": 1,
    "title": "Updated Post",
    "body": "Updated post content.",
    "file": "http://localhost:8000/media/posts/updated-file.pdf",
    "created_at": "2026-08-27T12:00:00Z",
    "updated_at": "2026-08-27T13:00:00Z",
    "role": "User"

Possible Error Responses
Unauthorized

Status Code: 401 Unauthorized

Returned when authentication credentials are missing or invalid.

Permission Denied

Status Code: 403 Forbidden

Returned when a normal user attempts to update another user's post.

Post Not Found

Status Code: 404 Not Found

## 13. Bulk Create Posts

### Endpoint

`POST /api/posts/bulk-create/`

### Purpose

Creates multiple posts in a single API request.

### Authentication

Token authentication is required.

### Content-Type

`multipart/form-data`

### Request Payload

| Field | Type | Required | Description |
|---|---|---|---|
| `posts` | JSON string | Yes | JSON array containing the posts to create |
| `files` | file list | Yes | One file for each post |

### Example `posts` Value

```json
[
    {
        "title": "Post 1",
        "body": "Body of post 1"
    },
    {
        "title": "Post 2",
        "body": "Body of post 2"
    }
]

Files

Upload one file for each post.

The files must be provided in the same order as the posts.

For example:

posts[0] → file for Post 1
posts[1] → file for Post 2
Successful Response

Status Code: 201 Created

The API returns the list of successfully created posts.

## 16. Roadblocks / Issues and Resolutions

### 1. File Upload Field Missing in Swagger

**Issue:**  
The `file` field was not appearing as a file-upload option in the Swagger POST request.

**Cause:**  
The serializer was using `SerializerMethodField()` for the `file` field. `SerializerMethodField` is read-only and therefore was not suitable for accepting uploaded files.

**Resolution:**  
Changed the serializer field to:

```python
file = serializers.FileField(
    required=False,
    allow_null=True,
    use_url=True,
)

The API also uses MultiPartParser and FormParser to support multipart file uploads.

##Role-Based Permission Implementation

Issue:
Posts needed to support different permissions based on the user's role.

Resolution:
Implemented a custom IsOwnerOrAdmin permission.

Admin users can update/delete any post.
Normal users can update/delete only their own posts.


## Role Filtering

Issue:
Posts and users needed to be filterable based on their role.

Resolution:
Added role information to the API responses and implemented role-based filtering through query parameters.

Examples:

/api/posts/?role=Admin
/api/posts/?role=User
/api/users/?role=Admin
/api/users/?role=User
